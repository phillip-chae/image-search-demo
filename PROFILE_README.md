## 🚀 Featured Projects

### [Image Search Demo](https://github.com/phillip-chae/image-search-demo)
> A production-style microservices platform for semantic image search.

- **Ingestion pipeline** — FastAPI endpoint + Celery/Redis worker that generates CLIP embeddings and stores images in MinIO
- **Search API** — Converts text queries to vectors and retrieves nearest matches from Milvus
- **CDN API** — Go (Gin) service for efficient image byte delivery by ID
- **Full stack** — Docker Compose orchestration with Traefik reverse proxy, devcontainer support

`Python` `Go` `FastAPI` `Celery` `Milvus` `Redis` `MinIO` `Docker` `Traefik`
